## Про проєкт

AgroNext7 — навчальний вебпроєкт, створений у межах лабораторних робіт із веброзробки.

## Структура сайту

- index.html — головна сторінка
- about.html — інформація про проєкт
- catalog.html — каталог
- calculator.html — калькулятор
- selection.html — сторінка вибору товарів
